# 个人与团队工作区同步（待下次发布）

验证日期：2026-11-02。当前正式版仍为 v0.1.5，本记录对应后续源码改动。

## 行为与范围

- 取消同一账号有多个组织目录时的切换拦截。目标仍严格匹配当前模式与 `lastKnownAccountUuid`，同步该身份下全部已存在的本地 Code 工作区。
- 用户通过 Claude 原生入口选择个人或团队。工具不写入或清空工作区选择 cookie，不按目录排序猜测活动组织，也不保证每次启动都会出现原生选择弹窗。
- 切换、首次保存、手动同步均补齐本地会话和定时任务。已有会话不覆盖；工作区自己的任务审批保留，新副本使用默认权限。
- 定时任务先统一解析各份定义、运行状态和删除意图，再在同一事务内写入所有目标。新增副本使用同一扫描起点，避免目录顺序影响结果；遇到冲突或失败整次回滚。
- `lastTargets` 记录上次成功同步的全部工作区，兼容 v0.1.5 的 `activeOwner`。当前源账号已跟踪工作区中，完整登记文件内移除任务可传播；整个文件缺失、新建空工作区不算删除。
- 清理旧账户目录前，当前账号每个工作区都必须完整保留任务、运行状态、跳过记录和提示词。
- 首次使用的工作区需先在 Claude 中进入 Code 建立目录，再运行同步。直接在 Claude 中切换工作区不触发本工具实时同步；云端聊天、云端项目和团队权限不在范围内。
